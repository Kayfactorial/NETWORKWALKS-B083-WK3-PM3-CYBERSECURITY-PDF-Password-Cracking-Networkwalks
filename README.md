## Project Overview

This project documents the third part of my Week 3 Ethical Hacking assignment with NetworkWalks.

The objective was to work with **My Locked PDF3** and demonstrate the process using the NetworkWalks hashing calculator and password-cracking functionality.

The exercise was performed as an authorized cybersecurity learning activity.

## Tools Used

* NetworkWalks Hash Calculator
* NetworkWalks Password Cracker
* Protected PDF document
* Web browser

## Methodology

The exercise followed these general steps:

1. Prepare the protected PDF for the exercise.
2. Use the NetworkWalks hashing calculator to process the PDF.
3. Obtain the relevant hash.
4. Use the NetworkWalks password-cracking functionality.
5. Recover the correct password.
6. Enter the recovered password into the protected PDF.
7. Confirm successful access to the document.
